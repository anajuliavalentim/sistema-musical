# 🎵 Artistas e Músicas — Sistema Web

## 📌 Sobre o Projeto

O projeto **Artistas e Músicas** consiste no desenvolvimento de um sistema web dinâmico, utilizando **HTML, CSS, PHP e MySQL**.

Inicialmente desenvolvido como um site estático na disciplina de LIMA, o projeto será aprimorado para se tornar um sistema funcional, integrado ao banco de dados desenvolvido na disciplina de Banco de Dados.

A proposta é transformar as páginas estáticas em uma aplicação web completa, aplicando na prática os conceitos de desenvolvimento backend e gerenciamento de informações.

## 🎯 Objetivo

Desenvolver um sistema web que permita o gerenciamento de artistas e músicas, utilizando PHP para processar as informações e MySQL para armazenar os dados.

O projeto também servirá como exemplo prático durante o semestre, auxiliando no aprendizado de novas funcionalidades e técnicas de programação.

## ⚙️ Tecnologias Utilizadas

- **HTML5:** Estrutura das páginas.
- **CSS3:** Estilização e organização visual.
- **PHP:** Desenvolvimento do backend e processamento de dados.
- **MySQL:** Criação e gerenciamento do banco de dados.

## 🚀 Funcionalidades

Durante o desenvolvimento, serão implementadas as seguintes funcionalidades:

- 🔐 Sistema de login e autenticação de usuários.
- 🛡️ Controle de acesso utilizando sessões PHP.
- 🎤 Cadastro de artistas.
- 🎵 Cadastro de músicas.
- 🔎 Consulta e visualização de registros.
- ✏️ Edição de informações cadastradas.
- 🗑️ Exclusão de registros.
- 🖼️ Upload e gerenciamento de imagens.
- 🔗 Integração entre PHP e MySQL.

## 📂 Material do Projeto

O material disponibilizado para esta etapa contém:

- Frontend estático desenvolvido na Fase 1.
- Arquivos HTML e CSS do projeto.
- Roteiro de implementação do backend para a Fase 2.

## 📚 Aprendizado

Com este projeto, serão desenvolvidos conhecimentos práticos sobre:

- Integração entre frontend e backend.
- Conexão com banco de dados MySQL.
- Operações CRUD (Create, Read, Update e Delete).
- Autenticação e sessões em PHP.
- Validação e processamento de formulários.
- Upload de arquivos e imagens.
- Desenvolvimento de sistemas web dinâmicos.

## 🏁 Conclusão

O projeto **Artistas e Músicas** representa uma etapa importante no aprendizado de desenvolvimento web, permitindo transformar um site estático em um sistema dinâmico e funcional.

Os conhecimentos adquiridos serão utilizados como referência para a criação de outros projetos durante o semestre, aplicando as mesmas técnicas em diferentes temas e propostas.
